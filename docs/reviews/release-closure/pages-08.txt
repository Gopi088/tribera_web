- "Interview three, hire one; if none of the three fit, we restart at no cost" — commercial guarantee terms.

- Role-level range claims in the roles grids (e.g., "Mid to director," "CRA to director") — scope accuracy per sector.

None of the above should block release on copy/design grounds; they are flagged only because they are factual assertions this review is not positioned to confirm.
