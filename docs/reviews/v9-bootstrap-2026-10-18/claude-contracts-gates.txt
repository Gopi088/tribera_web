### Follow-ups (not bootstrap blockers)
1. **Misleading evidence filename** — `artifacts/v9-bootstrap/legacy-regression.log` contains a crashed, failing run (`reviewed-bugs.test.mjs` assertion `true !== false`), not the passing result. The actually-cited evidence (`baseline-result.json` → `legacy-journeys.log`/`legacy-text.log`) is a later, clean run and is consistent with the "initialFailures" disclosure already in `docs/v9-execution-gates.md`. Not a false-green, but the stray top-level file name invites exactly the kind of "treat presence as proof" mistake this review is meant to avoid. *Fix: rename/relocate historical debug logs so only the referenced final logs sit at top level.*
2. **No generator for summary artifacts** — `artifacts/v9-bootstrap/bootstrap-status.json` and `baseline-result.json` are not produced by any script in the repo (`scripts/v9-gate.mjs` writes to `artifacts/v9-gates/*.json`, not these files). They appear hand-assembled from the individual gate outputs. Everything I spot-checked against raw logs was accurate, but the aggregation itself isn't reproducible/automated, so future summaries could drift from evidence without anyone noticing. *Fix: add a small script that builds these summaries from the individual gate JSON files.*
3. **Pre-existing legacy validation bug (not introduced by v9, found via comparison)** — `netlify/functions/_lib/job-catalog.mjs:11`, `findJobBySlug = (slug) => JOB_CATALOG[slug] || null` uses plain bracket access on a plain object literal. `findJobBySlug('constructor')` returns `Object` (truthy, inherited from `Object.prototype`), so legacy `careers-apply.mjs:65-68`'s `if (!job) return badRequest(...)` is bypassed, letting an application through with `Role: undefined`/`Department: undefined` in the outbound email. The new v9 adapter already avoids this via `Object.hasOwn`. This is a real, confirmed data-integrity defect in the **unmigrated legacy path**, out of scope for the files changed in this bootstrap. *Optional fix: backport the `Object.hasOwn` pattern into `findJobBySlug`.*
