# Private sector and Intelligence previews

`SectorPage.astro` renders all twelve sectors from `src/data/v9/sectors.json`. The JSON preserves the handoff sector records, adds the page-specific opening/role/closing copy and complete FAQs from each HTML page, and normalizes marketing uses of “dimensions”, “rubric” and “mandates”. Technical keys and URLs are retained. `SectorWeights` serializes only names and weights for the browser; the full editorial dataset stays in the build.

`IndustryChart` and `IndustryCards` use the same weights as the sector hero and comparison. `editorial.ts` now reads the serialized data for both these pages and the existing `/__v9/bfsi` preview. Keyboard selection, focus and pointer input take over from the automatic demonstration. Native disclosures and source links work without JavaScript; the index includes a full static weight table in that mode.

`IntelligencePage` retains the handoff's market, demand, method and source sections. `ScarcityLab` renders the eight sample distributions on the server. `src/data/v9/intelligence.json` deliberately has `sample: true`, null cohort/date/count fields and an explicit illustrative method. Its visible label and missing-cohort note are never hidden by interaction. Quarterly email subscriptions are explicitly in preparation, with a working link to the existing notification waitlist at `/blog#sub`. This does not establish provider/inbox delivery or independently verify the supplied external figures.

The page CSS retains the handoff's used selector families and cascade under local wrappers. Shared foundation behavior handles arrivals, ink and disclosures; editorial motion handles sector bars, questions and hero fields; `sector-charts.ts` adds line drawing, card-bar arrivals, function transitions and visible-only cycling. Static values and mini charts remain readable without scripts. Reduced motion cancels active animations and autoplay.

Private `/__v9/` routes exist only in development or `V9_PREVIEW=1` builds and are noindex and omitted from sitemaps. Public `/industries`, its twelve sector pages and `/intelligence` use the same components with public metadata. The GCC spelling alias redirects to `global-capability-centers`; Netlify has an explicit public 301 rule, with hosted behavior awaiting verification.

After `V9_PREVIEW=1 npm run build`, run `npm run test:migration:sectors`. Set `BROWSER=firefox` or `BROWSER=webkit` for the other engines. The runner starts Astro preview, records the build/source/lock hashes and dirty-tree status, and runs the page/data suite, existing editorial behavior, filled-ink regression and private navigation. It fails if the source changes during validation. Screenshots and results are written to `artifacts/v9-sectors/`; automated screenshots do not substitute for visual review or formal batch acceptance.
